# VPS Inventory Monitoring

Web-based WHMCS VPS inventory monitoring platform with admin backend and public storefront.

## Features

- WHMCS site monitoring and inventory sync
- Public inventory page with merchant grouping and filtering
- Admin dashboard, site management, country dictionary, and events
- Affiliate purchase links and click tracking
- Telegram sync notifications

## Run

```bash
npm install
npm run dev
```

Default admin account:

- username: `admin`
- password: `admin123`
